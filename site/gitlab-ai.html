gitlab-ai

A provider-neutral plugin for GitLab merge-request review, failed-pipeline repair, and repository agent-configuration auditing in Claude Code and OpenAI Codex.

review-mr

Uses a fresh-context worker selected by the shared model policy, removes prior bot feedback, posts warnings and suggestions in one summary, and reserves inline discussions for CRITICAL findings.

repair-pipeline

Waits for the latest branch pipeline, fetches failed-job logs, identifies actionable failures, and repairs the working tree while separating code defects from infrastructure failures.

audit-agent-config

Checks repository-scoped CLAUDE.md, AGENTS.md, skills, commands, and references against source. It reports or minimally repairs only confirmed contradictions and significant omissions.

Model policy

  • CI_TOOLS_REVIEW_MODEL defaults to logical tier high.
  • CI_TOOLS_AUDIT_MODEL defaults to logical tier fast.
  • Provider/task overrides such as CI_TOOLS_CODEX_REVIEW_MODEL take precedence.
  • Provider mismatches and unsafe values fail closed.

Install

# Claude Code
/plugin marketplace add AXXX-Institute/skills
/plugin install gitlab-ai@axxx-institute

# OpenAI Codex
codex plugin marketplace add AXXX-Institute/skills
codex plugin add gitlab-ai@axxx-institute
