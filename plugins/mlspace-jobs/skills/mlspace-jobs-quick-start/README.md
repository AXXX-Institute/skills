# mlspace-jobs-quick-start

Walk through first-time MLSpace Jobs setup one step at a time: create an
environment, install and configure `mls`, and submit and monitor a first job.

This skill is explicit-only and belongs to the `mlspace-jobs` plugin.

[Open the skill page](https://axxx-institute.github.io/skills/mlspace-jobs-quick-start/)

## Install

### Claude Code

```text
/plugin marketplace add AXXX-Institute/skills
/plugin install mlspace-jobs@axxx-institute
```

### OpenAI Codex

```bash
codex plugin marketplace add AXXX-Institute/skills
codex plugin add mlspace-jobs@axxx-institute
```

## Use

- Claude Code: `/mlspace-jobs:mlspace-jobs-quick-start`
- OpenAI Codex: `$mlspace-jobs:mlspace-jobs-quick-start`

Invoke it deliberately for a first setup. See [SKILL.md](SKILL.md) for the
interactive workflow and user-run command boundary.
