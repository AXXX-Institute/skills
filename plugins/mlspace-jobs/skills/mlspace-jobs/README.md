# mlspace-jobs

Use common `mls` commands to inspect, monitor, troubleshoot, and stop MLSpace
jobs after the CLI is installed and configured.

This skill belongs to the `mlspace-jobs` plugin.

[Open the skill page](https://axxx-institute.github.io/skills/mlspace-jobs/)

## Install

### Claude Code

```text
/plugin marketplace add AXXX-Institute/skills
/plugin install mlspace-jobs@axxx-institute
```

### OpenAI Codex

```bash
codex plugin marketplace add AXXX-Institute/skills
codex plugin add mlspace-jobs@axxx-institute
```

## Use

- Claude Code: `/mlspace-jobs`
- OpenAI Codex: `$mlspace-jobs`

Use the quick-start skill first if `mls` is not yet configured. See
[SKILL.md](SKILL.md) for the command reference and troubleshooting guidance.
